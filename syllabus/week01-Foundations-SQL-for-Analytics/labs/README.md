# Week 1 labs

The two in-class labs (**Lab 1.1** and **Lab 1.2**) are released here at the start of their class session,
each as a lab sheet (`week_01_lab_01_student.md`, `week_01_lab_02_student.md`) and a Marimo notebook
(`week_01_lab_01_student.py`, `week_01_lab_02_student.py`).

To work in a notebook, run `marimo edit week_01_lab_01_student.py` from this `labs/` folder (see the [week 0 software setup](../../week00-outline-and-TOC/README.md)).
