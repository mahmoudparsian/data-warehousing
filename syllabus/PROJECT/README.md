# Team Project

In teams of 2, you design, build and present your own data warehouse: raw data → Bronze → Silver → Gold star schema →
7 OLAP queries → a dashboard and a business story. The project is **30%** of the grade.

**Start with the guidelines**, then use the checklist to track your progress.
